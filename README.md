# 协同事务平台

协同事务平台为需要多机构参与的业务提供统一的机构、授权、案件、证据、审批、资源预约、资金分录、消息归并、通知、定时任务和历史回放能力。项目只使用 Python 标准库与 SQLite，适合在单个 Linux 应用容器内运行。

参与机构接入治理（数字货币桥证书轮换）在此基础上提供：

- 针对法律实体、监管辖区、接入环境、业务用途、证书链、密钥托管引用、路由白名单、限额与操作角色，保存带 `[effective_from, effective_to)` 生效区间的不可变配置版本。
- 启用、续期、吊销、重叠轮换、紧急降权均走“申请人提交 → 不同审批人批准”，分别产生可追查决定（批准人、原因、材料版本），并写入原有审计链。
- 重叠轮换允许新旧证书在窗口内同时有效；窗口内允许的角色与路由取当时各生效版本的并集。
- 新请求只能落入当时已生效（未过期、未提前）的配置，并按证书指纹钉住版本；已完成请求永远引用当时版本与材料。
- 机构申请人与证书审批人不能是同一人；无授权人员无法区分“参与者不存在”与“尚未获准”。
- 桥侧回执按来源编号与指纹归并：完全相同的消息只处理一次；编号不变而指纹变化时先隔离调查并通知，调查后可丢弃或以新指纹为准。
- 证书到期、待生效变更、异常回执与定期复核作为原有定时任务模块上的可恢复任务持续推进，通知走原有发件箱。
- 审计查询按指定时点列出被允许的机构、角色、路由，并展示每项决定的批准人及所依据的材料版本。

## 目录

- `src/civicflow/`：领域服务、SQLite 持久化、权限和命令行入口。
- `tests/`：核心流程、边界条件和异常路径测试。
- `examples/`：本地演示输入。

## 配置

通过 `CIVICFLOW_DB` 指定 SQLite 文件路径；不设置时命令行使用当前目录下的 `civicflow.sqlite3`。所有时间使用带时区的 ISO 8601 字符串。

## 测试

```bash
PYTHONPATH=src python3 -m unittest discover -s tests -v
```

## 编译或构建

```bash
PYTHONPATH=src python3 -m compileall -q src
```

## 使用

初始化数据库并运行离线演示：

```bash
PYTHONPATH=src python3 -m civicflow.cli --db /tmp/civicflow-demo.sqlite3 demo
```

查看当前案件：

```bash
PYTHONPATH=src python3 -m civicflow.cli --db /tmp/civicflow-demo.sqlite3 list-cases
```
